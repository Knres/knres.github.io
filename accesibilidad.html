Accesibilidad digital

Declaración de accesibilidad

La página trabajara para que sea accesible para el mayor número de personas posibles, con independencia de sus capacidades, dispositivo o entorno tecnológico. Esta declaración de accesibilidad se intentara basa en las WCAG 2.1 del W3C – Web Accessibility Initiative (WAI) .

Etiquetado semántico

Toda la estructura del sitio se ha desarrollado empleando etiquetas semánticas de HTML5 en la medida de lo posible ( <header>, <nav>, <main>, <section>, <footer>, etc. ) para mejorar la comprensión por parte de lectores de pantalla y navegadores especializados.

Además, se han utilizado atributos aria-label y alt en los elementos visuales y enlaces relevantes, de forma que el contenido sea interpretado correctamente por tecnologías de asistencia.

Aquelos elementos puramente decorativos se han omitido del marcado HTML o gestionado mediante CSS, para evitar distracciones o redundancias en la lectura de pantalla.

Uso correcto de los colores

Los colores que se emplearan intentaran respetar la identidad visual del sitio y cumplir con los niveles de contraste recomendados por las pautas WCAG 2.1 (nivel AA). Por defecto se emplearan fondos oscuror para reducir la fatiga visual, pero se ofreceran estilos alternativos que permitan aumentar el contraste o emplear fondos claros.

Selección de estilos

En navegadores que no soportan la selección de estilos alternativos (como Chrome o Edge), se puede utilizar el menú de accesibilidad propio del sitio o las extensiones de navegador para modificar el contraste o el tamaño del texto.

Una vez seleccionado un estilo alternativo, puedes guardarlo para que se aplique automáticamente en futuras visitas. (para ello, se emplea una cookie que almacena la preferencia del usuario).

Otras características de accesibilidad

  • Diseño adaptativo y responsive para diferentes dispositivos y tamaños de pantalla.
  • Compatibilidad con ampliación mediante zoom sin pérdida de funcionalidad.
  • Separación entre contenido y presentación mediante hojas de Estilo CSS.
  • Enlaces y botones accesibles con teclado y visibles en su estado de foco.
  • Uso de tipografía Arial y Roboto en los estilos accesibles para mejorar la lectura.

Compromiso de mejora

La página web trabajará para mejorar la accesibilidad. Si encuentra alguna dificultad para acceder a la información o funcionalidades, puedes contactar con Knres.
